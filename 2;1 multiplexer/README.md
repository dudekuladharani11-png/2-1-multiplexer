# 🔀 2:1 Multiplexer in Verilog

## 📖 Overview
This project implements a **2:1 Multiplexer** using Verilog HDL.  
A multiplexer selects one of the two input signals based on a select line and forwards it to the output.

---

## 🎯 Features
- Simple 2-to-1 multiplexer design  
- Testbench for functional verification  
- Simulation using **Icarus Verilog** and **GTKWave**  
- Easy-to-understand modular code
